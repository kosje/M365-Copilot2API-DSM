 手动粘贴方式说明

                
适合在浏览器拦截弹出窗口、或无法使用设备码时使用。登录后 Microsoft 会跳转到一个空白页面，地址栏里已经带了授权码，把它整段复制回来即可。

              

              
操作步骤：① 点击下方「开始手动授权」→ ② 在弹出页登录 Microsoft 账号 → ③ 页面变空白后，复制浏览器地址栏里的完整网址（形如 https://login.microsoftonline.com/common/oauth2/nativeclient?code=M.C5...&state=...）→ ④ 粘贴到下方输入框，点「确认添加」。

              
              

                
                

                  
                  
                

              

            


            

              

                
 推荐：设备码登录（无需配置）

                
这是最简单的方式，不需要在 Microsoft 后台做任何设置，也不会遇到「重定向地址」报错。

              

              
操作步骤：① 点击下方「开始设备码登录」→ ② 页面会显示一组用户代码和登录网址 → ③ 点击「打开」或复制网址到任意浏览器，登录 Microsoft 账号后粘贴用户代码并确认 → ④ 回到本页面，系统会自动等待并刷新，登录成功后账号自动加入，无需再复制任何内容。

Settings

        
自动探测并刷新所有账号的 M365 额度（剩余用量）。默认 300 秒；设为 0 关闭定时刷新。账号新增时也会立即刷新一次。
Token 即将到期前主动刷新（默认 21600 秒 = 6 小时），避免高峰期集中失效。刷新失败会触发告警通知。
请求超过上下文预算时，把被挤掉的历史用一次上游调用压缩成摘要并注入回上下文（而不是静默丢弃），适合整站审计等超长任务。响应头 X-M365-Context-Compacted: 1 标识生效。
被丢弃历史低于该值时直接截断，不消耗一次上游调用做摘要。默认 4000。
客户端写死 gpt-4o / claude-sonnet-4 等模型名时自动映射到已配置的公开模型，无需改客户端。目标必须是「模型管理」里已存在的公开模型。
支持飞书 bot / Bark / Telegram / 通用 JSON。触发事件：账号鉴权失败、Token 刷新失败、密钥配额耗尽、错误率超阈值。同类告警 1 小时内只发一次。
最近 60 分钟错误率超过该值（且样本 ≥ 20）时告警。每 10 分钟检查一次。
Choose the language used by the administration console.
