### Copilot2API v1.6.6 — 安全与可靠性修复

一次代码审查后的集中修复。**建议所有用户升级**，但先看下面的「升级须知」，有几处行为变更。

---

#### ⚠️ 升级须知

**1. ARM 机型将无法安装本套件。**
`INFO` 里的 `arch` 从 `noarch` 改为 `x86_64`。本项目只发一个 `linux/amd64` 二进制，此前标 `noarch`
会让 ARM 机型（DS223、DS220j 等）安装成功、然后二进制 exec 失败，套件长期处于「已停止」且看不出原因。
现在套件中心会直接拒绝在 ARM 上安装。若你用的是 x86-64 机型，无影响。

**2. 首次启动若未配置管理员口令，不再默认 `admin123`。**
此前未设置 `M365_ADMIN_PASSWORD` 时会用公开的默认口令引导，并只在首次登录后强制改密——而在改密之前，
任何能访问端口的人都能用这个公开口令登录并接管控制台。现在改为**生成随机口令**，写入
`<数据目录>/admin-password-bootstrap.txt`（0600）并打印到启动日志，首次登录必须修改，改完该文件自动删除。

> 套件安装向导里设过口令的用户不受影响；`M365_ADMIN_PASSWORD` 显式设成 `admin123` 会直接报错拒绝启动。

**3. 安装向导的口令下限从 8 位提高到 12 位**，与控制台本身的强度策略一致（原先 8 位入口能绕过 12 位策略）。

**4. 升级后请轮换已在使用的 API Key。**
此前 `GET /api/admin/keys` 会把**所有密钥的明文**返回给浏览器，且明文还被写进 `api-keys.json` 与
`users.json`（`/chat` 用户）。现在只存哈希、列表接口不再回传明文，历史文件里的明文会在启动时自动清除。
但**任何在此期间被日志、截图、浏览器插件或他人看到过的密钥都应视为已泄露**，请删除后重建。

**5. 管理控制台仍是明文 HTTP。** 这一版没有改变端口与加密方式（API 必须能被局域网客户端访问），
但服务在监听到非回环地址时会打印一条明确告警。若网络不可信，请用群晖反向代理套一层 HTTPS，
详见 [SECURITY.md](https://github.com/kosje/M365-Copilot2API-DSM/blob/main/SECURITY.md)。

**6. `/api/update` 现在需要登录**（控制台的版本提示不受影响）。

---

#### 安全修复

- 测试脚本里硬编码的**真实管理员口令与 API Key 已全部改为从环境变量读取**，仓库内已无该凭据。
- **API Key 明文不再落盘、不再回传**：`/chat` 代理改为按记录 ID 通过请求上下文完成内部鉴权，
  不再需要持有明文。
- **出站抓取增加拨号期地址校验**：图片与附件下载的 URL 来自模型输出，此前完全没有地址限制
  （一个不受限的抓取等于内网读取原语）。现在拒绝回环、私网、链路本地、CGNAT、云元数据地址，
  逐跳重定向复检，并要求响应确实是图片类型。
- **归档导入限制解压后大小**：此前 16MB 的上传可解压成数十 GB 直接打爆进程。
- 管理员**登出接口限定 POST**，`/metrics` 令牌改为常量时间比较。
- 前端 6 处错误信息直插 `innerHTML` 已转义，其中一处会渲染**未经解析的原始响应体**。
- 图标库从 `unpkg.com/lucide@latest` 改为固定版本并加 SRI 校验（此前浮动版本 + 无完整性校验，
  CDN 被投毒即等效控制台全站 XSS）。

#### 可靠性修复

- **修复请求永久挂起**：连接池的 park goroutine 在超时/异常退出时不释放读取方，导致请求永久阻塞
  并持续占用账号并发槽，累积后整个账号不可用；同时主循环的 5 分钟超时因为只在收到消息后重新求值而形同虚设。
- **升级/卸载不再可能静默丢账号**：快照与卸载留存移到包目录之外（`<卷>/@appdata/...`），
  复制失败会**中止升级**而不是继续，回填成功后才清理快照。
- 重装/修复不再「复活」你主动删掉的 API Key。
- 向导口令改为一次性文件交付，不再以明文常驻磁盘、也不再进入进程环境变量
  （`/proc/<pid>/environ` 对同 uid 进程可读）。
- 生成文件代理增加归属校验（此前任何已登录用户知道别人的会话 ID 就能取走其文件），
  会话上下文字典增加 TTL 淘汰（每条含一个 access token，此前从不回收）。
- 修复两处下标越界 panic（`data:image/` 前缀但无逗号的输入会崩）。
- HTTPS 代理不再因为代理地址是 IP 就**自动跳过证书校验**，改为需要显式开启。

#### 工程

- **新增 CI**：gofmt、build、vet、test、**`go test -race`**（此前从未运行过）、DSM 生命周期脚本的
  POSIX 语法检查、生命周期行为测试、完整 SPK 组装自检、linux/amd64 交叉编译。
- 仓库行尾统一为 LF（`.gitattributes` 显式声明），脚本补上可执行位——此前 README 让你跑的
  `./spk/build-spk.sh` 在**任何 Linux/macOS 检出上都会 Permission denied**。
- 版本号改为单一来源：`release.sh` 自动改写 `spk/INFO`；Release 附带 `checksums.txt`（此前只生成不上传）。
