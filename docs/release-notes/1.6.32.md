### v1.6.32 — 修正生图提示词并持久化图片

- 修复客户端把 `You are powered by the model ... tokens left` 作为末尾 user 消息时，网关把元信息当作生图描述的问题。当前连续 user 消息中的实际文字会合并，已知客户端提示会移除；不会跨越 assistant/tool 回合重新使用旧提示词。
- 显式生图请求若清理后没有有效描述，返回 400，不消耗配额生成无关图片。
- `/v1/images/files/` 图片改用数据目录下 `chat/generated-images/` 持久化存储。图片保留 72 小时，最多 128 张、512 MiB；达到上限会清理最旧文件。重启或升级后仍可读取未被清理的图片。
- 写入失败不返回成功链接；图片不存在、过期或读取失败会返回可读说明。下载链接无需登录，持有链接者可访问，建议及时另存。
- 修复图片 alt 文本按字节截断中文的问题。

验证：提示词分消息/分块注入、跨回合不重复生图、图片跨服务实例读取、20 分钟后仍可下载、72 小时过期、存储失败与容量清理回归测试通过；全量 Go 测试及 vet 通过。

本次没有在用户 NAS 上执行真实生图，也没有重启其服务。截图中旧链接的 404 已通过 HTTP 确认，但无法仅凭响应确定是到期、重启还是资源 ID/实例不一致。旧版已丢失的内存图片不能恢复，请升级后重新生成。覆盖升级，无需卸载。
