### Copilot2API v1.6.30 — 普通模型生图链路修复

本版同步同事上游至 **v1.6.29**，并针对 Claude Code / WorkBuddy / Mirasim 使用
`gpt-5.6-sol` 等普通模型生图时的异常链路做了合并加固。

#### 修复截图中的四个问题

- **不再先派通用子任务。** 客户端注入的 `<system-reminder>` 会先从用户提示词中剥离，
  “生成海报”可直接进入 GPT Image 2 管线，不再被注入块里的 code/tool 词误判成编码任务。
- **首次 502 自动换账号。** `empty completion`、429、单账号超时及可重试传输错误会轮换到
  尚未尝试的账号；多账号共用一个请求总超时，不会把单账号超时累加成数十分钟。
- **不再出现 `/mnt/data/...` 与重复伪附件。** 普通模型不会再自行调用其云端代码解释器；
  网关只返回已验证、已本地托管的 Markdown 图片与下载链接。
- **不再泄露 `cite call_<uuid>`。** OpenAI / Anthropic、流式 / 非流式输出都无条件清理
  ChatHub 内部调用与 citation 标记，与“公开身份重写”开关无关。

#### 同步上游 v1.6.29

- 生图支持尺寸、风格、数量（1–4）、排除项和高清选项，并显示每日图片额度。
- 生图文件剥离 C2PA / EXIF 元数据。
- 修复 WorkBuddy 注入 HTML 导致 Markdown 图片不显示。
- 工具轮次强制走非流式上游，客户端仍保持原来的流式协议。
- 同步 v1.6.8–v1.6.10 的长上下文工具调用与沙箱幻觉修复。

#### DSM 分支保留项

- 保留 v1.6.7 的安全修复、API Key 哈希存储、SSRF 防护、随机初始管理员密码、
  升级/卸载快照保护及审计日志滚动。
- 应用内只检测更新；实际升级仍由群晖套件中心完成。

升级无需卸载，账号、API Key 与设置会保留。
