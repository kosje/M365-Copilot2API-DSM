## 1. 飞牛 fnOS 安装指南（FPK）

### 1.1 安装步骤

1. 打开飞牛 **App Center → 手动安装**，选择 `m365-copilot2api.fpk`（从本仓库 [Release](../../releases) 下载）。
2. 安装向导共两步：
   - **监听地址:端口**：默认 `0.0.0.0:8080`（局域网可访问）；仅本机使用可改 `127.0.0.1:8080`。
   - **管理员密码**：网页管理后台的登录密码，建议 ≥12 位。**重新安装 / 升级时只要填的值与上次不同，安装完成即自动重置为该密码**（详见下节）。
3. 安装完成后浏览器访问 `http://<飞牛IP>:8080/` 进入管理后台，桌面同时出现应用图标。

### 1.2 升级 / 重新安装

- 直接在 App Center 里对应用执行「升级」或卸载后重装新的 fpk，**应用数据目录（账号、密钥、会话等）默认保留**。
- 升级不会改动你在网页端设置的管理员密码，除非你在向导里填了一个**不同的新密码**。

### 1.3 Docker / 源码部署

```bash
docker compose up -d          # 使用仓库自带 docker-compose.yml
# 或源码编译
go build -o m365-copilot2api ./cmd/server
M365_LISTEN=0.0.0.0:8080 M365_DATA_DIR=./data M365_ADMIN_PASSWORD='your-password' ./m365-copilot2api
```

## 2. 管理员密码与找回

### 2.1 密码规则（v1.0.8 起生效）

| 场景 | 行为 |
|------|------|
| 全新安装，向导填了密码 | 该密码即为管理员密码 |
| **重新安装 / 升级，向导密码与上次不同** | **直接重置管理员密码为向导新值**，无需任何额外操作 |
| 重新安装 / 升级，向导密码与上次相同 | 不覆盖——网页端改过的密码保持不变 |
| 日常重启服务 | 不覆盖网页端设置的密码 |

实现原理：环境密码以 SHA-256 摘要记录在 `<数据目录>/admin-envhash`，只有环境密码发生变化时才触发重置，兼顾「忘记密码一键重装」与「网页改密不被冲掉」。

### 2.2 忘记密码怎么办

**方法一（推荐，v1.0.8+）**：在 App Center 卸载（保留数据）重装本应用，向导里填一个新密码即可。

**方法二（免重装）**：在飞牛文件管理打开应用数据目录（`/vol1/@appdata/m365-copilot2api/data`），新建名为 `admin-reset` 的**空文件**，然后重启应用。启动后管理员密码被重置为向导密码字段当前值，`admin-reset` 文件会被自动删除。

> 密码使用 bcrypt 哈希存储，更换密码后旧密码立即失效；连续登录失败有防爆破锁定。

## 3. 桌面图标入口

安装后在飞牛桌面出现 **Copilot2API** 图标（微软 Copilot 官方图标；如未出现，重启一次 App Center 服务或重新安装应用）。

点击图标的行为：飞牛按 `{协议}://{你当前浏览器访问飞牛所用的域名或 IP}:{8080}/` 拼接跳转，因此：

| 访问场景 | 点击图标打开 |
|----------|--------------|
| 局域网内 `http://192.168.x.x` 访问飞牛 | `http://192.168.x.x:8080`（局域网直连） |
| 通过公网域名（DDNS / 反代）访问飞牛 | `https://你的域名:8080`（需路由器放行 8080，或反代映射） |

> 图标声明位于应用包 `ui/config`，入口类型为新标签页打开（管理台启用 `X-Frame-Options: DENY` 安全头，不适合 iframe 内嵌）。

## 4. 账号导入 / 导出

位置：管理后台 **Accounts（账号）页 → 「导入 / 导出账号」卡片**。

- **导出**：点击导出按钮，下载 `accounts-export-<时间戳>.json`，内容为 `{"accounts":[...]}`，**包含明文令牌**——请通过可信渠道传输，用完即删。
- **导入**：选择 `accounts.json`（本应用格式）或历史迁移归档 `m365-migration-*.tar.gz`，后端按账号 ID / 邮箱合并（已存在的更新，不存在的新增），**导入无需停机**。
- 典型用途：换机迁移、多实例同步、备份。

等价 curl（需管理员会话）：

```bash
curl -b "m365_admin_session=<cookie>" -F "file=@accounts.json" \
     http://<fnos-ip>:8080/api/admin/accounts/import      # 导入
curl -b "m365_admin_session=<cookie>" \
     -o accounts.json http://<fnos-ip>:8080/api/admin/accounts/export   # 导出
```

## 5. API Key 每日 / 总额度

位置：管理后台 **API Keys 页**。

- 密钥表格新增「额度」列，点击 **Edit** 可设置：
  - **每日额度**：该 key 每天最多成功调用次数（按自然日 0 点重置）；
  - **总额度**：该 key 累计最多成功调用次数；
  - 两项**留 0 或留空 = 不限制**。
- 超限调用返回 OpenAI 标准错误：

```json
{"error":{"code":"quota_exceeded","message":"daily quota exceeded for this API key","type":"insufficient_quota"}}
```

- 计数只统计**成功**请求，失败/被上游拒绝的调用不消耗额度；用量的按 key 统计可在「用量」页查看。

## 6. 国内 AI 工具一键接入

本网关提供标准 OpenAI 兼容接口（`/v1/chat/completions`），任何支持「自定义 OpenAI 兼容模型服务」的国内工具都能接入：**WorkBuddy、Trae、豆包、通义千问、Kimi、ChatBox、NextChat、OpenWebUI** 等。

**最简接入方式**：管理后台 → API Keys → 点密钥的 **Use key** → 第一个标签页「**国内 AI 工具**」：

1. 页面自动生成一段包含**真实 API Key** 与网关地址的提示词；
2. 整段复制，直接粘贴发送到目标 AI 工具的对话框；
3. 工具会提示配置模型服务，确认后即适配成功。

也支持手动配置，通用参数：

| 参数 | 值 |
|------|-----|
| API 地址（Base URL） | `http://<飞牛IP>:8080/v1` |
| API Key | 后台创建的密钥（`sk-m365-...` 或自定义前缀） |
| 模型名 | `auto`（自动路由）或「模型测试」页列出的模型 |

curl 验证：

```bash
curl http://<飞牛IP>:8080/v1/chat/completions \
  -H "Authorization: Bearer <你的APIKey>" \
  -H "Content-Type: application/json" \
  -d '{"model":"auto","messages":[{"role":"user","content":"你好"}]}'
```

## 7. /chat 网页对话端

访问 `http://<飞牛IP>:8080/chat`，登录管理员创建的对话账号即可使用。界面仿 DeepSeek Web 风格。

### 7.1 功能

| 功能 | 说明 |
|------|------|
| 文字对话 | 流式逐字输出，支持历史会话（左侧按日期分组），可新建/切换/删除会话 |
| 图片理解 | 输入框图片按钮上传（自动压缩为 data URL），AI 可识别图片内容 |
| AI 画图 | 输入框🎨开关切换画图模式，描述内容直接生成图片并内嵌展示 |
| 额度显示 | 侧栏底部与输入框下方实时显示「今日对话 x/N · 画图 y/M」（N/M=0 表示不限） |
| 会话持久化 | 消息保存在服务端 `data/chat/convs/`，换浏览器登录不丢历史 |

### 7.2 技术细节

- 对话请求由网关**进程内代理**到 `/v1/chat/completions` 与 `/v1/images/generations`，每个 chat 用户绑定一把专属 API Key，用量自动按用户归属统计；
- 每日额度按**成功次数**计（quota 文件按日滚动）；
- 上传图与生成图统一存 `data/chat/images/`，通过会话鉴权的 `/api/chatui/file/<id>` 端点访问，无会话不可读。

## 8. Chat 账户管理

位置：管理后台 **Chat Users（聊天测试）页**。

- **创建用户**：用户名 + 密码 + 每日对话额度 + 每日画图额度（0 = 不限），系统自动为该用户生成专属 API Key；
- **重置密码** / **启用 / 停用** / **删除**（删除会连同其专属 Key、会话与缓存图片一并清理）；
- 该体系**独立于管理员密码**，适合给家人/同事开测试账号而不暴露管理后台。

## 9. 存储管理与清理

位置：Chat Users 页底部的「存储与清理」卡片。

| 项目 | 说明 |
|------|------|
| 空间占用统计 | 实时显示会话、图片缓存各占多少 MB / 文件数 |
| 会话保留天数 | 超过 N 天未活跃的会话自动删除（0 = 永久保留） |
| 图片缓存 TTL | 生成/上传图片保留小时数，过期自动清理 |
| 容量上限 | 图片缓存总大小上限（MB），超限自动删除最旧图片 |
| 手动清理 | 「清理过期数据」按当前规则立即执行；「清空图片缓存」删除全部缓存图片 |
| 自动执行 | 后台每 30 分钟自动跑一次清理 |
